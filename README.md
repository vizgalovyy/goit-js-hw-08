# JavaScript Homework 08 Template

## Як розпочати роботу

1. Створи репозиторій goit-js-hw-08.
2. Завдання виконуй у файлах gallery.js та index.html.
3. Для стилізації розмітки використовуй цей макет.
4. Прочитай завдання і виконай його в редакторі коду.
5. Переконайся, що код відформатований Prettier, а в консолі відсутні помилки й
   попередження під час відкриття живої сторінки завдання.

## Важливо

1. Розмітка галереї.
2. Масив зображень.
3. Розмітка елементів галереї.
4. Стилі.
5. Делегування.
6. Підключення бібліотеки.
7. Модальне вікно.
8. Велике зображення.
